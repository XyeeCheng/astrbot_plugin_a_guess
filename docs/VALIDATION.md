# v1.1.0 验证记录

日期：2026-09-28。

## 已执行

- 本机 WSL Ubuntu 24.04，Python 3.12.3：`python3 -m unittest discover -s tests -v`，66 项测试通过（部分测试含多题/多组随机子用例）。
- 本机 AstrBot 4.28.1 Python 环境：真实框架导入、配置传入、插件初始化、唤醒过滤、普通消息不被拦截、开局、提示、结束与中文链接回复、停用取消任务、重载读取状态，冒烟检查通过。
- 题库：200个唯一Codeforces Educational题号，150普通、50困难；每题9层提示、中文题意、小例子、来源链接、复杂度及可解析的答案组合。
- 200道题逐一执行开局、提示1至9、正确答案和结算，核对原题链接与中文；全部算法别名往返解析无冲突，困难题不接受仅猜中组合中的单项。
- 十道困难题的核心算法均有小规模独立对照：异或区间计数、问号字符串匹配、二维坏点时刻、乘积数组计数、约数替换、互质数排名、桥树直径、逆序期望、排列容斥、二分图背包。
- 新增13道题的小规模独立对照：702D行驶决策、710E长度DP、803A字典序矩阵、825E拓扑标号、846B完整题奖励、846F随机端点期望、873D归并调用数、884D三路Huffman、893D存款区间、911C周期覆盖、938C反构造、954G城墙补人、985C木桶分组。对照使用枚举方案、最短路或独立直接计算，不把结构检查当作算法正确性证明。
- 回执检查、平台实例隔离、私聊/频道不转为群发、未知结果不自动重试，均使用明确的模拟平台接口测试。

## 验证边界

- 没有连接用户的 Ubuntu 云服务器进行安装，本仓库是可安装插件交付。
- 没有向真实 QQ 群发消息；QQ 官方主动消息权限、链接限制与真实群接收需云端安装后验收。
- 核心测试在 Ubuntu 上运行，AstrBot 适配冒烟在已安装的本机 AstrBot 环境运行，两者不是同一项测试。
- 算法小规模对照覆盖23题，不等于200道题都有独立评测器，也不等于在Codeforces提交并全测所有算法实现；本插件不接收用户代码进行评测。
- 200道题卡是当前发行内容；此前拉取的1,260条元数据索引不是1,260道已上线题卡。
