# v1.2.0 验证记录

日期：2026-09-28。下列结果为本机实际执行；云端部署和真实 QQ 收发不包含在内。

## 已执行

- WSL Ubuntu 24.04 / Python 3.12.3：`python3 -m unittest discover -s tests`，**125项通过，无跳过**。
- 本机 AstrBot 4.28.1 / Python 3.12：`tests/smoke_astrbot.py` 冒烟通过；`tests/framework_checks.py` **9项通过**。使用真实框架对象与模拟发送接口，未启动机器人。
- 125项包含原有94项回归、新增输入/恢复/规则测试、9项安装器测试、2项独立算法对照及空平台元数据测试。
- 对200道题逐一验证开局无提示、九层线索、正确答案和带中文/链接的结算；逐卡与整库 SHA256 均一致，普通150、困难50。
- 普通1354B/888C单猜二分可获胜，辅助算法不能随意单独通关；困难题仍需一次猜齐一套核心，同义词不占多个位置。
- 否定句不扣次、不获胜；支持末尾标点、紧凑命令、按题认可的 DP/前缀和/字典树名称。旧快照保留旧组合规则。
- 事件发送失败、部分分段失败、发送中取消、超时投递意外异常、重启恢复、开新局后的 `a上局`、同群顺序及跨群有界并发均有故障注入验证。
- 管理员申诉权限、会话隔离、处理中不剧透、旧 SQLite 申诉表增量迁移、原输入记录上限、可见版本和抽题策略均有断言。
- Ubuntu 安装器验证全新安装、旧源码备份、最终切换失败恢复、数据库和其他插件保持原样、清单改动拒绝、路径越界和符号链接拒绝。临时目录测试不触及 `/opt/phoebe`。

## 独立算法验证

小规模独立算法对照覆盖**29道题**，不是只检查题卡自己填写的答案：

- 原有10道困难题：异或区间计数、问号字符串匹配、二维坏点时刻、乘积数组计数、约数替换、互质数排名、桥树直径、逆序期望、排列容斥、二分图背包。
- 扩展13道：702D、710E、803A、825E、846B、846F、873D、884D、893D、911C、938C、954G、985C。
- v1.1.1追加4道：632B的DP/模拟、652D的扫描线/排名树/归并计数、961E扫描、911A相邻最小值。
- v1.2.0追加2道：1354B二分长度＋前缀计数，与直接枚举所有子串比较；888C二分长度＋滑动窗口，与字符位置最大间隔比较。两者穷举长度1至7、三种字符的所有字符串。

## 验证边界

- 未连接腾讯云服务器安装本版，也未向真实 QQ 群发消息。真实群接收、链接限制、主动消息权限与额度需安装后在用户指定群验收。
- 事件回复发送调用正常返回只记为 `event_reply`；不等同于用户已读。定时 QQ 群发必须得到平台消息 ID 才记为 `acknowledged`；不明结果不无限重发。
- 200题的游戏流程覆盖，不等于200题都有独立解题器。独立对照覆盖29题，未声称在 Codeforces 提交所有实现并通过官方全测。
- 发布包仅含源码、题卡、测试和文档；未包含原始群聊、对局数据库或机器人配置。
