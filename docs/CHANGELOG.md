# v1.2.0（2026-09-28）

- 200张题卡显式标注核心／辅助，普通版单核心通关，困难版完整组合通关；增加按题认可的 DP、前缀和、字典树和最短路名称映射。
- 阻止否定句误判，支持末尾标点及紧凑命令；增加离散化辅助步骤和原输入判定记录。
- 新增 `a上局`、管理员申诉列表与处理、版本和旧题卡提示。旧对局与历史继续保留。
- 事件结算在发送后确认；超时投递异常和取消会退出 sending 状态。跨会话使用有并发上限的发送队列，弱引用会话锁可回收；停用时等正在发送的指令收尾。
- 默认按题等概率抽取，可选按算法类别；消息去重清理增加索引并降低频率。
- Ubuntu 发布包包含 SHA256 文件清单与离线安装器，自动备份旧源码、安装失败恢复旧目录，保留数据库与配置。
- 修正632A题意中的“每天”为“这一天”。新增旧 SQLite 申诉表的增量迁移。

# 版本变更

## v1.1.1 · 2026-09-28

- 修复“二分”被一律拒绝为宽泛类别；二分、二分答案、二分查找共享判定与去重语义，兼容旧数据库键，一次最多计一个方法。
- 补充扫描线的常见中英文写法、算法名后缀，以及“和／与”连接，保护“前缀和”等完整名称。
- 652D、961E 增补扫描线组合；652D 增补带排名平衡树和归并分治；632B 增补动态规划与增量模拟；873D、911A 补充合理贪心思路；612D 允许排序、差分辅助步骤。
- 普通版支持组合多个同题已认可的单核心解法，困难版保持一次提交完整组合。反馈区分缺少方法与多余方法，并展示已命中数量。
- 新增24项匹配/游戏回归和4项独立算法对照，总计94项测试。用户原始群聊记录不包含在仓库中。
- 题库仍为200题，六张修订题卡版本升为2。已开局题卡保持快照；重载后新开一局使用修订答案。
